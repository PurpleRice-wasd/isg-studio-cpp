07

关键设计与差异

验收时需要知道“为什么这样做”，否则容易把翻译当成重写、把裁剪当成遗漏。

这是翻译，不是重写

纯逻辑 JS 逐字节复制；提示词逐字复制；只有 I/O、窗口、网络传输、解析、加密这些宿主能力才重新实现。oracle 仍在 apps/isg-studio/，不删不冻。

Key 不进页面

provider 配置给页面的是 __ISG_HOST_KEY__ 哨兵；net.cpp 发出前删掉哨兵头、注入真 Key，并核对 URL origin。渲染层拿不到明文。

两个方向都防大消息

宿主→页面分块（skill/契约/任务快照/回包）；页面→宿主也分块（revive 回包、finish 的 carry 裁剪、consoleErrors 截断）。单条 WebView2 消息超限会静默丢。

oracle 侧主动修了两处静默回归

pipeline/index.js 的 demos 映射补 checks；book.js 的 chapter.no 兼容 number。两处都先改 oracle、再 sync-web.ps1 逐字节同步。

删除前先看目标

探针副本按 _probe_<pid>_<序号>_ 形状认；ownsProbeCopy 区分“我们写的副本”和“demo 加载的原页面”；清理通道重新扫一遍清单，只删仍在清单内的路径。

最终交付补验

接手验收时补做的三件事，都是自动判据覆盖不到的；改动后已重新跑完 103 条外层判据（0 跳过、0 [BAD]）。

版本：C++ 2.0.0，Electron 1.4.2（有意分叉）

宿主从 Electron 换成 C++/WebView2 是主架构变更。C++ 版本唯一真源是工程根 VERSION，CMake、exe 的 VERSIONINFO、安装包都跟它走；Electron 1.4.2 保持不动，继续当迁移与对拍基准。两者共用 %APPDATA%\isg-studio，设置、OSCrypt Key、历史与旁挂数据仍互相可读。

200% 缩放下界面发虚 —— 已修

原 exe 清单没有 DPI 感知声明，Windows 会位图拉伸整个窗口。已补 PerMonitorV2 清单、VERSIONINFO、WM_DPICHANGED，并按 GetDpiForSystem() 把 DIP 尺寸换算成物理像素。实测进程 awareness=2、窗口 2360×1630 物理像素，截图清晰。

安装后立刻启动的控制器竞态 —— 已加兜底

“静默安装 → 立刻启动”序列里 CreateCoreWebView2Controller 偶发 E_ABORT（0x80004004）。现在失败后在计时器下一拍重试，最多 3 次（0.4 / 0.8 / 1.2 秒）。重试分支用临时强制失败钩子验证过，日志出现「第 1 次重试」后导航成功；钩子已删除。

安装版 + 单文件便携版 —— 已产出并实测

build-package/ISG-Studio-Setup-2.0.0-x64.exe（3.83 MB）与 ISG-Studio-Portable-2.0.0-x64.exe（3.79 MB）。安装版按当前用户安装、建快捷方式与卸载项，卸载保留 %APPDATA%\isg-studio；便携版解到 TEMP 运行、退出连空目录一起清掉。tools/package-acceptance.ps1 31 项全过。
