# 演示怎么写（拖一下就能懂的那些量）

演示的价值在于"**建立直觉**"：拖一个量，图和读数同时变，学生自己发现规律。所以选材只有一条标准——**这个量拖起来，某个结论会变得显而易见**（ch13 是 μ_r 放大倍数、同轴电缆分区、磁滞回线；ch14 是 ε = Blv 随 v、B 变化）。

- 标记骨架：`assets/demo-markup.html`（复制即用）
- 参考实现：`assets/demos-example.js`（ch13 三个演示）
- 验收：`assets/demo-probe.js`（拖滑块抄读数 + 查 SVG 越界）**＋ 手算核对 ＋ 截图**

## 一、三条铁律

1. **现算现画**：读数与图形都由公式当场算出来写进去。**图和读数必须来自同一套映射函数**——这样"数对不上图"这种错误在结构上就不可能发生。
2. **长度 ∝ 物理量**：箭头长度、条形长度都按公式值映射（可以压缩刻度，但要说明"按对数压缩"之类）。**别随手画一个好看的长度**。
3. **改完必须截图看一遍**：探针查得出"读数不对""元素越出 viewBox"，**查不出叠字、压线、标签贴边**。真踩过：曲线面板做窄了，滑块拉到最大时工作点标签被裁掉，只有截图才发现。

## 二、平面矢量图：怎么画才叫自洽

这类图（导轨 + 棒、圆环 + 磁场…）最容易画错，而且画错了"看着还挺专业"。定一套硬约定：

1. **先定坐标系，再动笔**：纸面 `x` 向右、`y` 向上、`z` 垂直纸面向外。**屏幕的 y 是向下的**，所以映射函数要翻：
   `py(y数学) = y0 − k*y`，`px(x数学) = x0 + k*x`。所有坐标都过这两个函数。
2. **方向老老实实算叉乘**：先按数学坐标算 `v×B`（或 `dl×r` 之类），**再**决定箭头朝哪；不要在屏幕坐标里凭感觉。
   例（ch14）：`v = +x`、`B = −z`（入纸）→ `v×B = (+x)×(−z) = +y` → 正电荷受力向上 → 电动势由下端指向上端、上端电势高。**算完再画**，就会和图一致。
3. **"⊥"要画成真垂直**：把导轨画成水平线、棒画成竖直线，用坐标保证（`y1==y2`、`x1==x2`），再在交点加一个小直角方块；别只靠肉眼。
4. **`×`（入纸）和 `⊙`（出纸）用 JS 铺**：按网格生成，并**跳过导体/箭头附近的那几列**，否则记号会压在字或棒上（ch14 那页就是这么做的：跳过 `|x − 棒x| < 26`）。
5. **自洽性自查（画完逐条过）**：
   - 该垂直的两条线，方向点乘 = 0；
   - 端点真的落在它该在的线上（棒的两端落在导轨上、圆弧端点落在圆上）；
   - 共线的两个箭头真的共线，且分居两侧时不穿越；
   - 电流/电动势的箭头首尾相接能闭合成你声称的绕向（如逆时针）。
6. 把解释性的句子放进 `figcaption` 或 `.say`，**图里只留符号和最短标签**，图面才干净。

## 三、曲线面板（单自变量时画什么）

只有一个滑块时，别只让数字跳——补一条曲线：
- 常见选择：**"读数—自变量"关系曲线**（ε–v 直线，斜率 = Bl）。再给第二个滑块（如 B），拖它时曲线**转动**、拖第一个时**工作点沿曲线移动**，两种拖动都看得到变化。
- 量程取"滑块极值时读数的最大值"再往上取整（例：ε 最大 1.44 V → 纵轴到 1.6 V）。
- **防越界/防压字清单**：端点标签、工作点标签、轴标题、刻度数字，四类都要留位；`viewBox` 四周至少留 8~12 单位余量；轴标题与刻度数字别贴同一行；改完用 `demo-probe.js` 查一遍越界，**再截图看一遍**。

## 四、验收（每个演示都要做）

1. `python assets/inject-probe.py 被测页.html verify-probe.js demo-probe.js` → 无头跑一次；
2. 看演示探针输出的读数，**拿公式手算核对**每个位置（写进你的报告："位置 → 读数 → 手算"）；
3. 看 `SVG 越界元素=0`；
4. 截图：浅色 + 深色各一张，看叠字、压线、裁切（这一步**不能省**）。
