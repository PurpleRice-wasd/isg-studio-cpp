# 陪练（右下角那个形象）规范

陪练是**可选**的附加件：有形象就出现，没有就完全不占地方。它管两件事——**形象从哪来**、**它说什么话**。
本文是这两件事的规范；引擎实现见 `../assets/quiz-engine.js` 里「陪练」那一段。

## 一、形象只有三个来源，二选一 + 一个"都不要"

| 来源 | 什么时候用 | 怎么启用 |
|---|---|---|
| **同目录的图片**（默认） | 用户自己找了张图 | 把图片命名成 `pet.png` / `pet.jpg` / `pet.jpeg` / `pet.webp`（也认 `venti.*`）放到 HTML **同一目录**，刷新即可；命中就同时当右下角圆形头像 + 全页淡背景 |
| **内置「大肥鱼」** | 用户没图、也不想找图 | 右键菜单 →「形象 · 内置大肥鱼」，或顶部开关的气泡里点「用内置的大肥鱼」。形象已以 `data:image/png;base64` 嵌进引擎，**不需要任何外部文件** |
| **都不要** | 只想安安静静做题 | 右键菜单 →「先藏起来」，或顶部开关切「关」。有图但不想用时同理 |

- 图片名在引擎的 `PAGE.petImages` 里配，按数组顺序**命中第一个存在的**。默认那 8 个是**裸文件名**，
  所以默认只能在同目录里找；想让图片放子目录（如 `img/pet.jpg`）必须在 `PAGE.petImages` 里写相对路径。
  **别把某一章的文件名写死在那里**——这是坑清单第 17 条的延伸：引擎里出现的名字要对所有章通用。
- 全页淡背景优先用 `PAGE.bgImages`（`pet-bg.png` 等）；那张没命中才拿头像那张铺。
- 一个形象文件都没有时，右下角**什么都不出现**（`display:none`，占位 0px），顶部开关显示「没放图」，
  点它给两条路：换成内置大肥鱼 / 教用户怎么放自己的图。**不要**退回一个内置的简笔画小人（用户明确否过）。
- 内置大肥鱼的素材来自第三方（MIT），见 `../third-party/dafeiyu-pet/`：要换、要删、要注意什么，那个 README 里写了。

## 二、交互（用户能对它做什么）

| 动作 | 反应 |
|---|---|
| 按住拖 | 跟着走，松手记位置（存 `localStorage`，换页回来还在原地）；拖动时内置形象会侧身并朝移动方向 |
| 单击 | 跳一下 + 说一句（按当前进度挑：还没做题 / 有错题 / 状态不错） |
| 双击 | 在「原地不动 / 跟着鼠标 / 自己溜达」之间轮换，并说出当前模式 |
| 右键（手机上长按 0.55s） | 开菜单：模式 · 大小 · 形象 · 回到右下角 · 先藏起来 |
| 顶部开关 | 开/关；没有形象时它是"放图指南"的入口 |

细节约定（改代码时别破坏）：

- **气泡必须 `position:absolute` 挂在形象边上**。让它参与文档流的话，气泡文字一长一短就会把形象挤得左右乱跳。
- 位置存的是**形象右下角到视口右下角的距离**（`{r,b}`），不是左上角坐标——这样换窗口大小不会跑到屏幕外，
  而且气泡长短永远推不动形象。贴到左边缘（`<250px`）时加 `.flip` 把气泡翻到右边。
- 视口尺寸一律读 `document.documentElement.clientWidth/Height`，**别用 `window.innerWidth`**（差一个滚动条宽度，
  拖动时形象会比手指偏十几像素）。无头校验里这个偏差还会让"回到右下角"对不上。
- 单击/双击**自己判**（`pointerup` 时按有没有移动 + 300ms 内是否是第二下），别跟原生 `click` 混用：
  `pointerdown` 里 `preventDefault()` 之后部分浏览器就不发 `click` 了，混用会一次点击处理两回。
- 跟随/溜达的补间用 `setTimeout(…,16)`，**不用 `requestAnimationFrame`**：rAF 在无头浏览器里常不推进
  （探针就没法验），标签页切后台也会停。到位就自己停，不空转。
- **姿态要有迟滞**：到站后先保持走姿 ~280ms 再回正面站姿（跟随鼠标时"停一下再动"很频繁，
  立刻换回正面就会来回闪）；朝向（镜像）只在 |位移|≥8px 且距上次翻面 ≥350ms 时才翻。
- **移动用固定速度**，别按距离变速：跟随鼠标时距离每帧都在变，变速会让人觉得"一抽一抽"
  （实测抖动比 4.8 → 固定速度后 1.4）。步进按**实际经过的时间**算（`speed*dt`），别用"每帧固定像素"。
- **"停下"是一个动作**：停定时器 + 清目标 + 姿态回正（`moving=false`、朝向归零）。只停定时器会出现
  "锁定侧身"——开菜单/切模式/开始拖动之后鱼永远侧着，切回"原地不动"也不正身。
- **菜单一打开就必须把形象钉住**（停掉在跑的补间 + 跟随/溜达全部跳过）。菜单是挂在形象上的绝对定位元素，
  跟随模式下用户一往菜单挪，形象就带着菜单一起挪 —— **永远点不到**（用户实测踩过）。
- **菜单要按剩余空间决定朝上还是朝下展开**，两边都放不下就限高 + 纵向滚动。形象靠视口上方时，
  固定朝上展开会让菜单顶出屏幕（实测顶边 y=-123），里面的项照样点不到。横向同理（贴左时改成向右展开）。
  验收办法：打开菜单后 `document.elementFromPoint(按钮中心)` 必须命中那个按钮本身（比看坐标硬）。
- 系统开了「减少动态效果」（`prefers-reduced-motion: reduce`）时：形象不浮动、不给「自己溜达」这个选项。
  **注意 CSS 那条要写到足够的权重上**（`.pet .fig.hasimg` 带 `animation`，媒体查询里只写 `.pet .fig` 是压不过它的，等于死代码）。
- **气泡必须给宽度**：`width:max-content`（外加 `width:230px` 给老浏览器兜底）+ `max-width` + `max-height` + `overflow:auto`。
  原因见第五节第 1 条——`.pet` 是 `position:fixed` 且宽度收缩到形象那么宽，绝对定位的气泡在里面算出的可用宽度是负数，
  会一路掉到 min-content，整句话被排成每行两三个字的细长条，长台词还会顶出视口上沿。
- 改完尺寸（菜单里的「大/中/小」）要**重新夹一次位置**：形象原本贴着左/上边时，放大 25% 就会越界 18~24px，
  得把 `moveTo(pos.r,pos.b,true)` 再走一遍。
- 每个功能块都包在 `try{…}catch(e){console.error(…)}` 里——陪练写崩不许连累题目。
- 页面**可以整块删掉陪练标记**：引擎对 `#pet / #petBubble / #petFig / #petToggle` 全部做了判空，
  `say()` 自动变空操作，顶部那个开关会被自动藏起来（不留死键）。删掉整块之后建议跑一次探针确认
  「题库/进度/结算」都还在（`【陪练·残缺】` 那一行就是干这个的）。

## 二·补 「自己溜达」到底怎么算的

它不是一个独立定时器一路走，而是"停一会儿、走一小段、再停一会儿"：

| 环节 | 默认值 | 在哪配 |
|---|---|---|
| 用户停手多久才开始溜达 | **4 秒**（`petRoamIdle`） | `PAGE.petRoamIdle` |
| 每隔多久看一眼要不要再走一段 | **3 秒**（`petRoamTick`） | `PAGE.petRoamTick` |
| 一段走多远 | 随机 110～260 px（按视口大小取一个比例） | 引擎里 `reach` |
| 走多快 | **120 px/秒**（`petWalkSpeed`），所以一段走 1～2 秒 | `PAGE.petWalkSpeed` |
| 跟随鼠标的速度 | 420 px/秒（`petFollowSpeed`），**恒定**（不按距离变速） | `PAGE.petFollowSpeed` |

**什么时候不动**：用户在动（鼠标/滚动/键盘/触摸，`petRoamIdle` 毫秒内有活动）、菜单或设置面板开着、
正在被拖、系统开了「减少动态效果」、页面不在 roam 模式 —— 任一命中都不走。

**界面上能直接调**（不用改代码）：右键陪练 →「溜达设置…」→ 面板里四个滑块 + 三个预设：

| 面板上的项 | 改的是什么 | 范围 |
|---|---|---|
| 跟随速度（跟鼠标） | 跟随的基础速度（px/秒）。**调大＝跟得更紧、越不容易落后**；距离远时还会按增益加速（封顶 `PAGE.petFollowMaxSpeed`，但用户自己的值不会被封顶吃掉） | 200–3000 px/s |
| 走路速度 / 步频 | 溜达的移动速度（px/秒），**同时**决定走路动作的快慢（`--walkdur` 跟着算） | 30–400 px/s |
| 每段走多远 | 一次决策最多挪多远 | 60–420 px |
| 间隔（多久走一段） | 走完一段后，隔多久再看要不要走下一段 | 1–15 s |
| 停手多久才开始 | 你停手多久它才敢动 | 1–20 s |
| 预设：安静 / 标准 / 活泼 | 四档参数一起换（标准 = `PAGE` 里的出厂值） | — |
| 恢复默认 | 清掉用户改过的值，回到 `PAGE` 的出厂默认 | — |

用户在面板里改的值存在 **localStorage**（跟着页面的存盘键走，每页各自记），
`PAGE.petRoamIdle / petRoamTick / petWalkSpeed / petFollowSpeed` 只是出厂默认。改完**立刻生效**，不用刷新；面板开着时形象会冻结（和菜单同理）。

**走动时的"运动 ing"状态**（`.fig` 上的 `.moving` 类）：换侧面立绘、按移动方向镜像、播放走路动作
（`practice.css` 的 `walk` 关键帧：小幅上下 + 左右轻摆，0.46s 一轮）；到站去掉 `.moving`，回到正面站姿 + 慢浮动。
自查：控制台看 `__PET__.roam()` 拿到当前节奏参数，`__PET__.position()` 看它在不在动。

> 两条踩过的坑：① **别用指数衰减插值**（`pos += (goal-pos)*0.16`）做移动——距离一大三四帧就冲完，看着像瞬移；
> 要用匀速（px/秒）。② **`moving` 类是加在 `.fig` 上的**，写选择器时别写成 `.pet.moving`；而且走路动画的权重
> 要压得过 `.pet.happy .fig.hasimg`（那个类会挂一会儿），否则走动时看到的是"跳"不是"走"。

## 三、台词（用户想用自己的话，就照这一节写）

引擎里所有陪练台词都抽成了一张表，**每一句都能被用户自己的文本顶掉**。

### 3.1 键位表

| 键 | 什么时候说 | 类型 |
|---|---|---|
| `hello` | 打开陪练时 | 数组 |
| `back0` / `backN` | 页面加载完、**还没做过题** / **有作答记录** | 数组 |
| `right` / `wrong` | 答对 / 答错 | 数组 |
| `hint` | 点「思路提示」 | 数组 |
| `done` / `all` | 某一关刚做完 / 整章做完 | 数组 |
| `filter` | 勾上「只看错题」 | 数组 |
| `empty` | 点形象、一题没做 | 数组 |
| `wrongN` | 点形象、有错题（`{n}`＝错题数） | 数组 |
| `fine` | 点形象、状态不错 | 数组 |
| `modeSay` | 换模式（`{m}`＝模式名） | 数组 |
| `modeTail` | 换模式的后半句：`{follow:'…',roam:'…',stay:'…'}` | 对象 |
| `modeName` | 菜单里三个模式叫什么：`{stay:'原地不动',follow:'跟着鼠标',roam:'自己溜达'}` | 对象 |
| `noArt` | 没有形象时气泡的第一句 | 数组 |
| `howTo` | 点了「怎么放自己的图」 | 数组 |
| `fishOn` | 切到内置大肥鱼 | 数组 |
| `noArtBtn1` / `noArtBtn2` | 气泡里两个按钮的字 | 字符串 |

**数组 = 随机挑一句**：写一句就只有那一句；写多句（多行）每次随机说一句。
占位符只有两个：`{n}` 错题数、`{m}` 模式名——而且**只有 `wrongN` 与 `modeSay` 这两句会被替换**，
别的键（`empty`/`fine`/`hello`/`done`…）写了 `{n}` 会原样显示。
**字符串型键（`noArtBtn1`/`noArtBtn2`）不能用纯文本格式设置**：`linesFromText` 一律产出数组，
而字符串键只收字符串 → 会被安静地丢掉、保留默认；要改按钮文案请用对象形式。

### 3.2 四种注入方式（优先级从低到高，后面的顶前面的）

1. **引擎里的默认表** `DEF_LINES`——不用管。
2. **页面配置块** `PAGE.petLines`：
   ```js
   var PAGE={ key:'ch14-…', finalAdvice:'',
              petImages:[…], bgImages:[…],
              petLines:{ right:['漂亮！'], modeName:{stay:'站着'} } };
   ```
3. **页面里的内联 JSON 块**（单个 HTML 文件交付时最省事，位置在引擎脚本之前）：
   ```html
   <script data-petlines id="petLines" type="application/json">
   {"right":["这题稳了"],"wrong":["再看一眼解析"],"hint":["提示只给方向"]}
   </script>
   ```
4. **同目录的 `pet-lines.js`**（"用户上传一个文本文件就能用"就靠它）。**必须排在引擎脚本之前**：
   ```html
   <script src="pet-lines.js"></script>   <!-- 引擎脚本之前 -->
   ```
   放后面**不会报错，只是完全不生效**（引擎的 IIFE 在它之前就把台词表建好了）——静默失败，最容易白折腾。
   内联 JSON 块同理：块也要在引擎脚本之前。
   文件里两种写法都能用，**对象形式优先级最高**：
   ```js
   /* 纯文本：一行一句，"键: 话"，同键多行 = 多句随机；# 或 // 开头是注释 */
   window.PET_LINES_TEXT = `
   right: 这题稳了
   right: 漂亮，继续
   wrongN: 你现在有 {n} 道错题，先看解析
   modeSay: 现在是{m}
   `;
   /* 想精确控制（数组长度、modeName 这类对象）就用对象形式 */
   window.PET_LINES = { hint: ["提示只给方向"], modeName: { stay:"站着" } };
   ```

### 3.3 容错（写坏了会怎样）

- 认不出的键、`modeName` 用纯文本写的、没有分隔符的行 → **一律安静跳过**，不报错、不影响别的键。
- 内联块的 JSON 有语法错误（尾逗号之类）→ 只有**那一块**失效，控制台一句 `陪练台词 JSON 解析失败（petLines）：…`，
  其余来源照常生效。
- 某个数组写成了空数组 → 回退成内置默认（否则 `pick()` 会挑出 `undefined`，气泡变空白）。
- 页面里没有 `pet-lines.js` 但写了那个标签 → 控制台会有一条 404 记录，功能不受影响（别慌，补上文件就行）。

### 3.4 写完怎么确认"认出来了"

- 有探针：在 skill 目录下跑 `python assets/inject-probe.py 页面.html pet-probe.js`，
  结果里 `【陪练·跟随】在用台词 right=… empty=… hint=…` 打印的就是**引擎实际在用的那几句**；
- 手边有浏览器：控制台敲 `__PET__.lines`（**给的是副本，改它不会影响页面**；`__PET__.art()` 看当前用的是图片还是内置大肥鱼）。

## 四、验收清单（动过陪练就逐条过）

探针会按页面状态打三种标签：`【陪练·无图】`、`【陪练·有图】`、`【陪练·跟随】`，
页面残缺时还有 `【陪练·残缺】`（报"引擎有没有被连累、开关是不是死键"）。

1. `python assets/inject-probe.py 页面.html verify-probe.js pet-probe.js` → 无头跑一遍，看上面那几行：
   - 没图的页面：`陪练形象=无`、`形象占位=0px`、`display=none`、开关=「没放图」、气泡里有两个按钮；
   - 有图的页面：`陪练形象=同目录图片`、`背景启用=是`、拖动有位移且存盘、双击换模式、右键菜单 10 个按钮；
   - 选了内置大肥鱼的页面（在引擎脚本前预置 `localStorage` 里 `ui.petArt='fish'`）：`陪练形象=内置大肥鱼`、`已内嵌12KB`、跟随模式位移 > 0。
2. **气泡量一下宽度**：写一句长台词（控制台 `__PET__.say('……很长一句……')`），气泡宽度应该是 ~230px、
   顶边不出视口，而不是一条每行两三个字的细长条。这条探针量不了，靠眼睛/尺寸。
2. **截图**：浅色 + 深色各一张，看形象有没有被裁、气泡有没有出屏（探针查不出这两样）。
3. 三个尺寸都点一遍（小/中/大）——手机的 `--petbase` 会在基础上再缩，别让它缩到看不清或顶出屏幕。
